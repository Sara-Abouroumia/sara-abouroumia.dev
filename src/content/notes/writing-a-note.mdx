This file is a template and a reference. It is marked `draft: true`, which
means it renders on localhost and on preview deployments but never on the
production site. Copy it, rename it, delete everything below, and write.

The filename becomes the URL. This one is `writing-a-note.mdx`, so it lives at
`/notes/writing-a-note`.

## Frontmatter

The block at the top of the file is required and validated at build time. A
missing or misspelled key fails the build with the filename in the message,
rather than shipping a note with a blank summary.

| Key | Required | Notes |
| --- | --- | --- |
| `title` | yes | Used as the h1, the page title, and the feed entry title |
| `summary` | yes | The card, the meta description, and the RSS description |
| `category` | yes | One of `lecture`, `study`, `paper`, `finding`. Drives the card label and the filter |
| `date` | yes | `YYYY-MM-DD`. Sorts the index, newest first |
| `draft` | no | Defaults to `false`. `true` hides it in production only |
| `tags` | no | Topics, free-form (`intrusion detection`, `transformers`). Defaults to none |

The four categories:

- `lecture`: notes taken from a course or a talk
- `study`: working through a topic on your own
- `paper`: a summary or critique of a paper or article you read
- `finding`: something you worked out, measured, or got wrong and fixed

**Quote any title or summary that contains a colon.** YAML reads `: ` as the
start of a new key, so `title: Networks: TCP` fails the build, while
`title: "Networks: TCP"` works. The same goes for an empty tag list: write
`tags: []`, not a bare `tags:`, which YAML reads as "no value" rather than
"no tags".

## Headings

Start at `##`. The title in the frontmatter is already the page's only `h1`,
so a `#` here would create a second one and break the document outline for
screen readers and search engines alike.

## Code

Fenced blocks are highlighted at build time. There is no syntax-highlighting
library in the browser: the colours are baked into the HTML, in both themes at
once, and the page picks the right set.

import pandas as pd

def load(path: str) -> pd.DataFrame:

    return frame.set_index("timestamp").sort_index()

```ts
type Split = { train: number[]; test: number[] };

export function chronological(rows: number[], ratio = 0.8): Split {
  const cut = Math.floor(rows.length * ratio);
  return { train: rows.slice(0, cut), test: rows.slice(cut) };
}
```

## Reading time

Counted from the prose only. Code blocks, import lines and JSX are stripped
before counting, because thirty lines of Python is not thirty lines of
reading. The figure in the byline is words divided by 200, rounded, with a
floor of one minute.
